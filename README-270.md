# 270 版本更新摘要

本分支发布现有 V3.0 演示版本，基线为 V2.4（`versions/v2.4`）。版本号 `270` 用于 GitHub 分支，应用版本为 `0.3.0`。

## V3.0 相比 V2.4 的更新

1. **新增调度单工作台。** 提供调度单列表、关键词与状态/风险筛选、汇总指标和详情页；详情展示运输轨迹、事件、关联运单及扩展信息。入口为 `/index/dispatches`。
2. **补充多装多卸、多车运输展示。** 调度单展示提货和卸货站点、车辆与司机；运输详情按车辆区分轨迹和事件，便于查看分段运输过程。
3. **增加运单与调度单关联。** 零担运单可在演示数据中合并生成调度单；运单列表和详情补充运输类型、调度单号、装卸计划、车辆顺序及扩展信息。
4. **扩展运单导入演示。** 增加接口数据和表格数据导入入口，支持装卸货点、车辆顺序及自定义展示字段解析；导入的装卸货点进入知识库待确认。
5. **完善在途展示与研判。** 运单详情和监控页调整事件与风险展示，补充轨迹检测、异常停车及离线等场景的展示和处理逻辑。

## 运行与边界

在本分支执行 `pnpm install --frozen-lockfile`、`pnpm dev`；默认地址为 `http://127.0.0.1:5830`。构建命令为 `pnpm build`。

此分支是 V3.0 演示代码。接口导入、调度单合并及案例数据在本地演示，不代表已接入客户系统。高德地图凭据需在本地单独配置；实际环境变量文件不纳入版本库。
