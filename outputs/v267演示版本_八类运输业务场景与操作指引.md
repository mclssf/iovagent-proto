# 八类运输业务场景：演示清单与操作指引

适用分支：`v267演示版本`。保留向导编号 **2–9**；场景 1「在途监控」不在本次演示范围，原有产品功能不变。案例使用前端虚构运输台账，作业日期统一为 **2026-10-22**。不读取真实客户台账，不发送短信，不改账或放行车辆。

## 开场准备

1. 打开 `/index/agent` → **新对话**，或进入项目 **华东运输核查 → 智能体工作台**。
2. 点击模型旁的 **数字人技能**，搜索下表中的技能名称，点卡片**右上角「召唤」**。推荐提示词进入输入框，可修改；只有点「发送」才开始处理。侧栏同名入口使用相同卡片。
3. 单票演示直接发送推荐提示词。批量演示则点输入框的 **下载输入样表**，上传该 Excel 后再发送，表内记录优先于推荐词中的示例编号。也可使用[仓库内的输入样表](../public/demo/east-dispatch-input.xlsx)。
4. 若运营环境自定义过技能加载关系，在 `/agent-ops` 的客户 Agent 配置中，为对应客户的通用对话或项目对话 Agent 加载所需技能。不要通过重置所有浏览器数据覆盖现有配置。

## 场景清单

各技能均支持按**运单号或车牌**查询、上传 Excel 批量处理。以下按现场讲解顺序排列。需要看地图的单票结果有「在运单地图查看」卡片。

| 场景 / 召唤卡片 | 单票提示词与后续操作 | 预期结果 / 批量产物 |
|---|---|---|
| 2. 装卸货地追溯留证 | 「追溯 YD261002 的装卸地点和依据」→ 追问「截图留证」；或召唤后直接上传样表。 | 单票先返回 07:40–08:16 苏州候选装货停靠、10:46–11:18 嘉定收货及待核凭证。留证进入普通任务，ZIP 含合并运单结果表、成功记录的水印 JPG 及相对路径；补全字段标色。 |
| 3. 运短骗长核查 | 「YD261002 的申报里程是否包含上一票？」→「为什么？」→ 点击地图卡。 | 对比 **2,230 km 与约 82 km**，差额 2,148 km。车辆来向不等于本票起点，建议补磅单和前票交接文件。Excel 另列两种里程与差额。 |
| 4. 轨迹造假分析预警 | 「核验苏E53202的签到是否与轨迹一致」→ 查看地图上的签到跳点。 | 09:50 昆山、09:51 嘉定签到，门禁首见 10:42，相差 51 分钟；仅列疑点，不直接认定造假。Excel 按票区分有无跳点。 |
| 5. 车机离线监控提醒 | 「沪A56101断流了多久，恢复了吗？」→「整理提醒」。 | 显示 09:42 至 10:03 中断 **21 分钟**，超过 15 分钟阈值且已恢复。追问生成未发送的调度文案。Excel 列出离线及恢复依据。 |
| 6. 异常停靠与偷串货预警 | 「YD261002 途中有没有非授权停靠？」→ 地图卡 → 选中周转场事件。 | 昆山东部周转场 09:12–09:50 停靠 38 分钟，无调拨授权记录；建议核对封签、交接单，不把停车定性为偷货。 |
| 7. 同城倒短运单生成与监控 | 「为苏E76325生成同城倒短运单」→ 打开地图卡或到 **华东运输核查 → 运单列表** 搜索车牌。 | 生成 DT261001、DT261002、DT261003；2 趟卸货配对，1 趟待补。重复执行不重复建单。Excel 一车多趟展开，逐趟列发车、卸货与状态。 |
| 8. 装卸图片核验 | 召唤后上传自己的 JPG、PNG 或 WebP，再发「核验 YD261001 的装卸照片」。未上传时系统会追问，直接补传即可。 | 工作台显示**实际上传图片的缩略图、文件名、尺寸、曝光/对比度及人工核对事项**。不判断照片真伪、货物数量或是否签收。批量操作见下节。 |
| 9. 进场车辆核查 | 「苏E53202是否满足进场条件？」→「是否到过苏州市？」或「是否到过山东省？」。 | 按授权起运场站和非授权停靠规则给出现场复核建议；地区追问返回本票节点的到访依据或未查到。Excel 可按提示词附加查询地区、到访记录和时间。 |

## 批量与下载

1. 任选一张上述技能卡召唤，保留推荐词。上传样表并发送，点击会话中的 **查看普通任务**，进入所属工作区的「做任务」。只有一行的 Excel 也走任务，不受旧流程的 100 行阈值限制。
2. 在任务运行面板看解析、匹配、逐行核查与归档。一般场景直接下载 **核查明细.xlsx**；也可从公共 **下载** 页按任务标题找到同一文件。源文件、原始行号、失败原因会保留，未匹配编号不自动替换。样表 4 个输入中有 1 个车牌对应 3 趟，普通核查因此输出 6 行。
3. **图片批量**：解压[六张原始样图与关联表](v267_装卸图片核验_操作素材.zip)。召唤「装卸图片核验」，把包内 Excel 和六张 JPG 一起上传后发送。关联表也可在召唤后的输入框点「下载图片关联表」取得。结果 Excel 六行分别对应地磅车辆、尾部包件、车辆正面、装载包件、篷布覆盖、车辆及货厢，包含画面内容、尺寸和核对事项。故意漏选一张可验证该行失败，其他行仍输出。单票可只上传任一张原图，保留推荐提示词发送。

   关联表内的运单号、车牌是讲解用关联，不代表照片中的实际车牌或已证明某次运输。六张指定原图按文件内容指纹匹配人工整理的画面说明；其他照片也可上传，仅进行浏览器本地可读性检查，不冒充通用视觉识别。原图只在本地素材包，未放入网站公共资源。
4. **截图留证**：样表中 YD261002 具备完整起止记录；YD261001 未到末站，苏E76325 有多趟需补单号，YD269999 无记录。用这些行可展示同一 ZIP 中的成功和失败。仅在高德地图与道路服务正常且地图截图有效时生成 JPG；否则在结果表记录原因，不放占位图。截图依赖现有地图密钥、代理与域名白名单，建议演前在实际演示域名试一次。
5. 自由对话创建个人普通任务；项目会话创建项目普通任务。地图卡指向台账所属的「华东运输核查」，不会把这票运单写进其他项目。回到最近对话可以继续追问上一票的依据或处理建议。
